# 码字 - 打字练习软件

对标金山打字通的打字练习 Web 应用,核心特色:拼音打字系统以拼音输入进度实时追踪。

## 功能

- **拼音打字**:汉字上方显示拼音,输入拼音时实时高亮已输入部分,完整匹配后自动跳字
- **英文打字**:键位练习、单词练习、文章练习
- **数字符号**:数字、符号、混合练习
- **打字测试**:限时测试(1/2/5/10 分钟)、限字测试(50/100/300/500 字)
- **打字游戏**:字母雨、单词射击、拼音雨
- **统计中心**:速度趋势图、历史记录、成就系统、等级经验
- **设置**:深色/浅色主题、字体大小、音效、键盘提示、拼音模糊匹配

## 使用方法

用浏览器打开 index.html 即可运行,无需安装任何依赖。

## 技术栈

纯前端 HTML/CSS/JavaScript,数据存储在 localStorage。
拼音数据由 pinyin-pro 库生成,内嵌 20856 个汉字的拼音映射。
